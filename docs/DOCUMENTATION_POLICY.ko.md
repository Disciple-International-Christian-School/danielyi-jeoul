# 문서·근거 관리 정책

**Language / 언어:** [English](DOCUMENTATION_POLICY.md) | [한국어](DOCUMENTATION_POLICY.ko.md)

## 언어 선택

기본 *.md는 영어, 같은 위치의 *.ko.md는 한국어다. 상단에서 같은 문서의 언어를 선택하고 본문 연결도 선택 언어를 유지한다. 기존 README.en.md·docs/README.en.md·docs/KEY_ISSUES.en.md는 과거 링크 호환용으로 남긴다.

GitHub에서는 문서 URL이 바뀌며 전체 사이트의 선택 언어를 저장하지 않는다. 저장소와 기본 경로는 영어로 열린다. HTML에는 언어 버튼, 용량 PDF에는 영어 첫 화면과 영·한 이동 링크가 있다. 원본 스크린샷/PDF는 한국어 보관 자료로 표시하고 번역된 읽기판을 제공한다. 이미지 안의 글자까지 번역했다고 표현하지 않는다.

가독성을 위해 과거 서술을 재구성할 수 있으나 실질적인 판단·날짜·수치·식별자·한계·중단 조건은 보존한다. 재구성판을 글자 그대로의 대화록이라 부르지 않는다. 일지의 중복 번호와 기술 근거를 보존하고 오래된 링크·설계는 상태를 명시한다.

## 갱신

두 언어를 같은 PR에서 수정한다. 상태 변경에는 이관/PR 또는 날짜 있는 검증 근거를 단다. 코드·SQL·버전·명령은 일관되게 유지한다. 운영에 필요한 한국어 UI 원문은 설명과 함께 둘 수 있다.

npm run check:docs는 언어 쌍·상호 선택 링크·내부 경로/앵커·언어 유지·목록 누락·계정 양식의 6자리 PIN 유사값을 검사한다. CI는 새 PR 커밋의 한국어 포함 여부도 검사한다.

## 커밋·이력

제목·본문·스쿼시 메시지를 모두 영어로 작성한다. 과거 커밋 메시지는 PR로 직접 수정되지 않는다. 재작성하면 해당 커밋과 후속 해시가 바뀌고 서명이 무효화된다. 준비된 대응표와 절차는 이력 관리 문서에 있다. Owner가 예상 head 조건을 걸고 main을 이동하기 전 별도 미리보기 브랜치에서 검토한다. 공동 브랜치를 조용히 강제 갱신하거나 기여자를 바꾸지 않는다. 일반 스쿼시는 과거 이력 번역이 아니다.

## 학교·EC 근거

구현·과거 운영 관측·가상 UI 시험·미완료 보급·계획을 구분한다. 소량 동등성 검사를 대규모 성능이나 보안 인증으로 표현하지 않는다. 개인 기여를 PR/커밋으로 연결하고 AI 지원을 공개한다. 효과 수치·단독 저작·도입률·입시 결과를 만들지 않는다.

실제 학생 명부·PIN·인증정보·연결표를 제출 자료에 넣지 않는다. 현재 파일 정리는 과거 Git 복사본 삭제나 비밀번호 교체가 아니다. 접근 공유 전 Owner가 실제 과거 노출을 처리해야 한다.

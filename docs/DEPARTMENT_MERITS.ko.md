# 부서 소속과 자동 상점

**Language / 언어:** [English](DEPARTMENT_MERITS.md) | [한국어](DEPARTMENT_MERITS.ko.md)

2026-10-27 갱신. 수기 입력 시험 초기화 후 사용자의 지시로 자동 상점을 재개했다. [초기화 기록](OPERATIONS_2026-10-27.ko.md)의 자동화 중지 상태를 대체한다.

기존 상점 규칙 4개와 월요일 00:00 KST Cron을 다시 활성화했다. 이번 주 초기화로 사라진 적격 소속의 자동 상점만 복구했다. 과거 초기화 사건과 비현재 주간 원장은 보관하고 수기 입력도 보존했다. 반복 생성·Cron 실행에서 중복 상점은 없었다.

소속 기간은 [starts_on, ends_on)이다. 오늘 종료하면 오늘 명단·부서 인원수에서 즉시 제외한다. 이전의 종료일 포함 조건은 당일까지 남기는 오류가 있었으며 주간 적격성·명단·소속 RPC 조회에 같은 경계를 적용했다.

주간 상점은 월요일 소속 여부로 결정한다. 화요일 종료자는 이번 주 상점을 보존하지만 현재 명단과 다음 월요일 대상에서는 빠진다. 월요일 종료자는 그 월요일 대상에서 제외한다. 종료했다고 기존 지급분을 삭제하지 않는다.

중지된 부서나 비활성 학생의 기존 소속도 종료할 수 있다. 추가는 활성 부서·학생만 허용한다. 같은 날 가입·종료·재가입도 중복키 오류 없이 처리한다. 처리 중 종료 버튼을 비활성화하고 완료 후 점수·이력을 다시 조회한다.

롤백 시험은 당일 종료 가시성·종료일 이력·당일 재가입·부서 중지 중 종료를 검증했다. 기록된 운영 점검은 현재 소속 35명, 당일 종료 행 노출 0, 이번 주 자동 상점 38/38건이다. 현재 인원과 월요일 적격 인원은 서로 다른 날짜 기준이므로 수가 다를 수 있다.

## 교사 상벌점 입력 (2026년 11월)
1. 교사 식별, 등교일 달력, 상벌점 원장과 공지 조회 경로를 확인한다.
2. 교사 입력을 예약하고 취소와 반영을 직렬화해 기존 원장에 한 번만 기록한다.
3. 교사 입력 화면, 개인 이력, 선도부용 주간 종합 기록을 연결한다.
4. 롤백 SQL 리허설, 회귀 검사, 타입 검사와 빌드 후 운영 적용을 준비한다.

교사 활동은 입력일 기준으로, 학생 처분은 실제 반영일 기준으로 집계한다.

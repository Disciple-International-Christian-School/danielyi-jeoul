# 현재 점수 표시와 생활지도 규칙

**Language / 언어:** [English](DISCIPLINE_RULES.md) | [한국어](DISCIPLINE_RULES.ko.md)

2026-10-28 갱신. 로드맵·원본 스펙·과거 일지의 기준보다 이 운영 결정을 우선한다. 같은 문서 안에서도 후속 절이 앞선 시점의 상태를 대체할 수 있다.

## 점수와 징계위원회

- 주간 상벌NET = 해당 월~일 상점 − 벌점. 누적NET은 관리자가 시작·종료하는 현재 정산기간의 상점 − 벌점이다.
- 주간 체력훈련 기본 기준은 NET -8 이하 또는 벌점 발생 기록 3회 이상이다. 상점은 점수를 상쇄하지만 횟수는 줄이지 않는다. -8은 해당하고 -7만으로는 해당하지 않는다. 아래의 2배 미제출 기준도 별도로 적용한다.
- 징계위원회는 현재 학기에서 체력훈련 대상인 달력 주차가 3주 연속이어야 한다. 정산 시작일·누적NET과 독립이며 중간 주가 빠지면 연속이 끊긴다. 이전 20점·비연속 3주 대안은 제거했다.
- physical_training_weeks는 현재 학기부터 정산 종료까지의 최장 연속 대상 주차를 표시한다.
- 이관된 주간값에서 알 수 없는 발생 횟수를 만들지 않는다. 보관·삭제된 사건은 제외하고 초기화된 과거 원장은 비현재로 유지한다. 중지했던 자동 상점은 [부서상점 기록](DEPARTMENT_MERITS.ko.md)에 따라 재개했다.
- net_penalty_points 같은 내부 호환 필드는 벌점−상점이다. 화면은 구성값에서 상점−벌점을 명시적으로 계산하며 대상 판정은 DB가 담당한다.

기록된 SQL 롤백 검증은 정산 경계를 넘는 3주 연속, 중간 주 누락, 연속 없는 20점, 상점으로 상쇄된 낮은 점수의 벌점 3회, 2회, NET -7/-8을 포함한다. 시험 행은 남기지 않는다.

## 반성문 대상 — 10월 28일

월~일 주간 NET이 음수인 경우만 대상이다. 벌점이 있어도 NET 0 이상이면 대상이 아니다. 해당 벌점 입력 시점의 누적 NET도 음수로 전환·유지되어야 한다. +10, -5, -6에서는 -5가 상쇄되고 -6에서 NET -1이 되어 첫 대상이 된다. 앞선 상쇄 기록이 소급 2배가 되면 안 된다.

후속 상점으로 NET이 0 이상이 되면 대상·미제출/2배 배지·공지·이력 상태를 비활성화한다. 원기록과 반성문 감사행은 삭제하지 않는다. 다시 음수가 되면 이후 적격 벌점이 대상이 된다. 이 시점에서 기존 주간 기준·마감·과거 원장은 유지했다.

v_reflection_eligible_penalties가 입력 순서의 누적 NET과 현재 주간 NET을 결합하며 반성문·점수·일일 공지·학생 요약 뷰가 함께 사용한다.

## 공지·상태·담당범위 — 10월 28일

ELEMENTARY G1–6, MIDDLE G7–8, HIGH G9–12다. 반성문과 이력 접근 범위가 일치해야 하며 학생 학년 자체는 바꾸지 않는다.

오늘 공지는 오늘 미제출 적격 반성문과 과거 발생 건 중 현재 DOUBLE인 미제출을 합친다. 제출완료·주간NET 비적격은 실행 대상에서 제외하되 감사 이력은 유지한다. 과거 날짜 공지는 이월하지 않는다. 현황판 오늘 대상 수도 같은 기준이다.

2배는 기존 빨간 배지, 체력훈련은 짙은 남색이다. 출력·현황판 주간 상점은 +0, 벌점은 −0, NET은 상점−벌점의 부호를 유지한다.

## 체력훈련 추가 사유 — 10월 28일

벌점 주간 3회 이상, 주간 NET -8 이하, 2배 반성문 17시 미제출 후 익일 중 하나면 해당한다. 동시에 해당하는 사유를 모두 화면·출력에 표시한다.

최초 마감이 17시 이전이면 해당일 17시, 이후라면 다음날 17시를 2배 제출 확인 시각으로 사용한다. 제출완료 시 2배 미제출 사유는 해제하고 다른 조건은 독립 유지한다. 3주 연속 판정에서 한 미제출 건은 최초 대상 주차 1회만 인정해 중복 주차를 막는다.

# 현재 점수 표시와 생활지도 규칙

**Language / 언어:** [English](DISCIPLINE_RULES.md) | [한국어](DISCIPLINE_RULES.ko.md)

2026-11-06 갱신. 로드맵·원본 스펙·과거 일지의 기준보다 이 운영 결정을 우선한다. 같은 문서 안에서도 후속 절이 앞선 시점의 상태를 대체할 수 있다.

## 점수와 징계위원회

- 주간 상벌NET = 해당 월~일 상점 − 벌점. 학기 누계는 점수 이력에서 조회한다.
- **개정 전 기록:** 과거 주간 체력훈련 기준에 포함됐던 `벌점 3회 이상` 조건은 2026년 11월 개정에서 **삭제**했다. 주간 NET -8 이하 또는 2배 반성문 2차 마감 미준수만 인정한다. 적용 중인 계산 뷰에서도 벌점 횟수를 대상 판정에 사용하지 않는다.
- 징계위원회는 현재 학기에서 체력훈련 대상인 달력 주차가 3주 연속이어야 한다. 정산 시작일·누적NET과 독립이며 중간 주가 빠지면 연속이 끊긴다. 이전 20점·비연속 3주 대안은 제거했다.
- physical_training_weeks는 현재 학기의 최장 연속 대상 주차를 표시한다.
- 이관된 주간값에서 알 수 없는 발생 횟수를 만들지 않는다. 보관·삭제된 사건은 제외하고 초기화된 과거 원장은 비현재로 유지한다. 중지했던 자동 상점은 [부서상점 기록](DEPARTMENT_MERITS.ko.md)에 따라 재개했다.
- net_penalty_points 같은 내부 호환 필드는 벌점−상점이다. 화면은 구성값에서 상점−벌점을 명시적으로 계산하며 대상 판정은 DB가 담당한다.

기록된 SQL 롤백 검증은 정산 경계를 넘는 3주 연속, 중간 주 누락, 연속 없는 20점, 상점으로 상쇄된 낮은 점수의 벌점 3회, 2회, NET -7/-8을 포함한다. 시험 행은 남기지 않는다.

## 반성문 대상 — 10월 28일

월~일 주간 NET이 음수인 경우만 대상이다. 벌점이 있어도 NET 0 이상이면 대상이 아니다. 해당 벌점 입력 시점의 누적 NET도 음수로 전환·유지되어야 한다. +10, -5, -6에서는 -5가 상쇄되고 -6에서 NET -1이 되어 첫 대상이 된다. 앞선 상쇄 기록이 소급 2배가 되면 안 된다.

후속 상점으로 NET이 0 이상이 되면 대상·미제출/2배 배지·공지·이력 상태를 비활성화한다. 원기록과 반성문 감사행은 삭제하지 않는다. 다시 음수가 되면 이후 적격 벌점이 대상이 된다. 이 시점에서 기존 주간 기준·마감·과거 원장은 유지했다.

v_reflection_eligible_penalties가 입력 순서의 누적 NET과 현재 주간 NET을 결합하며 반성문·점수·일일 공지·학생 요약 뷰가 함께 사용한다.

오늘 공지는 오늘 미제출 적격 반성문과 과거 발생 건 중 현재 DOUBLE인 미제출을 합친다. 제출완료·주간NET 비적격은 실행 대상에서 제외하되 감사 이력은 유지한다. 과거 날짜 공지는 이월하지 않는다. 현황판 오늘 대상 수와 반성문 기본 목록도 같은 기준이다. 반성문 목록에서 미제출 전체와 주차별 기록을 따로 조회한다. 반성문과 공지에는 발생 주차의 상벌NET과 해당 처분의 마감을 표시한다. 정산 관리 화면을 종료하고 징계위원회 판정은 학기 기준으로 직접 계산한다.

2배는 기존 빨간 배지, 체력훈련은 짙은 남색이다. 출력·현황판 주간 상점은 +0, 벌점은 −0, NET은 상점−벌점의 부호를 유지한다.

## 공지 게시와 주간·월간 결산 — 2026년 11월 개정

다니엘의 저울이 소유한 discipline 스키마에 시행 시각을 설정하면 새 규정을 적용한다.
첫 주를 온전히 결산할 수 있도록 월요일 시작 시점에 적용한다. 마이그레이션은 시행
시각을 자동 지정하지 않는다. 시행 전 반성문의 판정과 기한은 당시 기준을 따른다.
시행 전 상점은 이미 사용한 분량을 확인할 수 없어 새 반성문 상쇄에 이월하지 않는다.

- 선도부장은 **공지·출력 → 일일 반별 공지**에서 출력 마감을 확정하고 목록을 인쇄해
  게시한 뒤 게시를 확정한다. 출력 마감 이전에 접수된 새 건을 포함한다. 공지 재인쇄에
  사용할 항목과 원래 사유를 게시 기록에 남긴다.
- 상벌점 접수 시각은 기록 입력 시각과 지정된 발생일의 시작 시각 중 늦은 값이다.
  상점은 실제 접수 시각 이후 발생한 벌점에만 적용한다. 유효기간은 T~T+4, 총 5등교일이며 주말·공휴일·등록된 학교 재량휴업일은 카운트하지 않는다. 비등교일에 입력된 상점은 다음 등교일을 T로 삼는다.
  벌점 발생 시 유효하고 아직 사용하지 않은 **선행 상점**을 낮은 벌점부터 차감하며, 주간 경계를 넘어도 남은 점수를 사용할 수 있다. 공지 게시 시 반성문 페이지를 확정하고, 게시 후 발생한 상점은 이미 게시한 반성문에 소급 적용하지 않는다.
- 중고등은 게시 당일 17시와 다음 등교일 17시, 초등은 게시 후 첫째와 둘째 등교일
  08:20을 각각 첫째·둘째 마감으로 쓴다. 등교일 계산에서는 주말과 등록된 공휴일을
  제외한다. 2026년 남은 공휴일과 2027년 관공서 공휴일을 포함했다. 이후 공휴일과 DICS 재량휴업·휴교일은
  미리 `discipline.seondo_holidays`에 등록한다.

  넘겼다면 해당 마감 주의 체력훈련 사유로 기록한다. 주간 NET은 해당 주 상벌점으로

  해당 월 체력훈련이 3회 이상인 G7–G12를 징계 대상으로 확정한다.

## 2026-11-20 — 미게시 공지와 관계없이 제출기한 유지

출력 마감이나 게시 확정을 하지 않아도 원본 `reflection_records.due_at`을 기준으로 2배를 판정한다. 오늘 미리보기에서 과거 최초 기한을 오늘로 바꾸거나 DOUBLE을 MISSING으로 되돌리지 않는다. 2차 기한은 등교일 기준을 사용하며, 원본 페이지의 2배를 한 번 적용하고 제출할 때까지 유지한다.

마이그레이션 `20261120022738_reflection_deadlines_without_publication`은 학생 원본 기록과 과거 공지 항목을 보존한다. 이월 출력본에 원본 배치 연결을 두어 최초 반성문과 상점 배분은 한 번만 유지한다. 연속 날짜 출력 마감의 고유 인덱스 충돌도 해결했다. 출력 마감과 게시 확정은 제출기한을 재시작하지 않는다.

운영 선도부 권한으로 확인한 결과, 11/18 대상 8건과 11/19 대상 21건이 적용 후 모두 `is_double=true`로 반환됐다. 롤백 검증에서도 같은 결과를 확인했다. 가상 데이터로 미게시 상태, 중고등·초등 기한, 연속 날짜 및 중복 마감, 이전 페이지·기한 보존, 제출 완료 제외, 주말 제외를 검증했다. 프론트 배포 후 실제 브라우저 화면 확인은 남아 있다.

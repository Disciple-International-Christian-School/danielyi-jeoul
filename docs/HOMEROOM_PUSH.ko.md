# 담임 웹 푸시

**Language / 언어:** [English](HOMEROOM_PUSH.md) | [한국어](HOMEROOM_PUSH.ko.md)

담임은 `/teacher`에서 등록된 구글 계정으로 로그인합니다. CORE의 교직원 계정과 현재 학기 학급 연결을 사용합니다. 담당 학급 조회 전용 RPC만 허용하며, 상벌점 입력이나 관리자 권한은 부여하지 않습니다. 이메일 확인 여부는 `auth.users`에서 검사하며 사용자가 수정 가능한 JWT 메타데이터는 권한 판단에 사용하지 않습니다.

기기마다 알림을 직접 등록합니다. 아이폰은 홈 화면에 추가한 웹 앱에서 사용합니다. 브라우저 알림 허용 후에도 인증된 구독 등록이 성공해야 서버에 연결됩니다. 로그아웃하면 해당 기기의 구독을 해제합니다. 페이지를 닫아도 등록은 유지되며 세션이 만료된 경우 알림을 눌렀을 때 다시 로그인합니다.

DB는 기존 `v_reflections` 기준을 매분 확인합니다. 일반 미제출과 2배 제출 전환은 별도 이벤트입니다. 기존 대상자는 초기 기준에만 등록하며, 기기 등록 이후 새로 관측한 이벤트만 발송합니다. 발송 직전 대상 유효성, 교직원 활성 상태, 인증 계정 이메일, 현재 학기 담당 학급과 기기 구독을 재확인합니다. 회당 최대 10건을 처리하고 최대 5회 시도하며, 404/410 응답으로 만료된 구독은 해제합니다. 같은 알림 태그로 중복 표시를 줄이지만 정확히 한 번 전송을 보장하지는 않습니다.

VAPID 키와 발송 인증 토큰은 클라이언트 접근이 없는 비공개 테이블에 보관합니다. Edge Function은 자체 토큰 검증을 수행하며 서버 전용 RPC로 설정과 발송 대기열에 접근합니다. 푸시 주소는 Google, Mozilla, Apple의 지원 도메인으로 제한합니다. 잠금화면 알림에는 학생 이름이나 벌점 사유를 넣지 않습니다. 알림을 누르면 항상 같은 사이트의 담임 화면으로 이동합니다.

실제 계정과 키는 Git 외부에서 등록합니다. `core.staff_accounts`의 확인된 이메일과 `core.homeroom_staff`의 기존 학급 UUID를 연결합니다. 학기나 담임이 바뀔 때 함께 갱신해야 합니다. 계정 이메일 변경이나 교직원 비활성화 시 조회를 차단하고 대기 알림을 취소합니다. 교직원 소속 종료 시 기존 구독도 정리합니다.

검증: 빌드·타입 검사, `supabase/tests/homeroom_push.sql`의 롤백 SQL 검사, 서비스워커 검사와 운영 발송 서버의 빈 대기열 응답을 확인합니다. 구글 로그인 리다이렉트 완료와 담임 휴대전화 실제 수신은 별도 운영 검증입니다. 먼저 테스트 알림을 받은 뒤 다른 담임에게 확대합니다. 구글 로그인 후 다른 앱으로 이동하면 기존 앱 설정을 유지한 채 Supabase Auth 허용 URL에 정확한 `/teacher` 주소를 추가합니다.
